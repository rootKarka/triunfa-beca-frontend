# Triunfa Beca Frontend

Quiero desarrollar el FRONTEND de una página web moderna, profesional y responsive para una academia educativa llamada **TRIUNFA BECA**.

La página debe estar orientada principalmente a padres de familia, escolares, estudiantes de secundaria y jóvenes que buscan preparación preuniversitaria o asesoramiento para postular a Beca 18.

IMPORTANTE:

* Por ahora SOLO desarrollar el frontend.
* NO implementar pagos.
* NO implementar base de datos.
* NO implementar autenticación.
* NO implementar backend.
* Los formularios solamente deben tener validaciones frontend y mostrar mensajes de confirmación simulados.
* La prioridad es crear una interfaz profesional, atractiva, moderna y fácil de utilizar.
* Debe funcionar perfectamente en desktop, tablet y móvil.

La combinación debe transmitir:

Cuando el usuario haga clic en:

* "Quiero asesoramiento"

## 16. Responsive Design

La página debe estar completamente optimizada para:

* Desktop
* Laptop
* Tablet
* Smartphone

En móvil:

* Navbar convertido en menú hamburguesa.
* Cards en una sola columna.
* Formularios adaptados al ancho de pantalla.
* Botón de WhatsApp siempre visible.
* Hero optimizado para pantallas pequeñas.
* Tipografía perfectamente legible.
